# Referencias de diseño

Archivos `DESIGN.md` de [voltagent/awesome-design-md](https://github.com/voltagent/awesome-design-md)
(MIT license) — documentos de sistema de diseño de marcas reales, para usar
como referencia de estilo al pedirle a una IA que ajuste el diseño del
sitio. No se aplican solos a nada; son solo material de consulta.

- `Airbnb.md` — paleta, tipografía y componentes de Airbnb.

Para agregar otra marca: `voltagent/awesome-design-md` en GitHub, carpeta
`design-md/<marca>/DESIGN.md`.
